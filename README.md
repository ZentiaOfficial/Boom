# Verdant · Compact Fertilizer Studio

เว็บ 3D Interactive ภาษาไทย สำหรับสำรวจแนวคิดกล่องผสมปุ๋ยอัตโนมัติ สร้างใน `/Users/knight/Development/Boom`

## เปิดใช้งาน

ต้องมี Node.js ที่รองรับ Vite 8 (ตรวจในรอบนี้ด้วย Node 24.18.0)

```sh
npm ci
npm run dev
```

เปิด http://127.0.0.1:4173 ใช้ WebGL2 และเปิด hardware acceleration ในเบราว์เซอร์

```sh
npm test
npm run build
npm run preview
```

หยุด dev server ก่อนเปิด preview เพราะใช้พอร์ตเดียวกัน เว็บผูกกับ loopback เท่านั้น ไม่ได้เผยแพร่สู่สาธารณะ ไฟล์และฟอนต์ใช้จากเครื่อง ไม่มี CDN, analytics, login, backend หรือการเชื่อมต่อฮาร์ดแวร์

## ใช้งาน

- หมุน/ซูมโมเดล เปิด–ปิดประตู แยกชิ้นส่วน หมุนอัตโนมัติ เปิดป้าย และขยายเต็มจอ
- กดป้ายหรืออุปกรณ์เพื่อดูรายละเอียด และเลือกดูตำแหน่งในโมเดล
- จอหน้าตู้เป็นจอไม่สัมผัส ปุ่มกด 3D ด้านนอกตู้ใช้เลือกสูตร เริ่ม ปล่อย และหยุดฉุกเฉินได้เมื่อเห็นด้านหน้าปุ่ม
- เลือกสัดส่วนมวลวัตถุดิบ 1:1:1 / 2:1:1 / 1:1:2 และน้ำหนัก 0.5 / 1 / 2 กก.
- กดเริ่ม: จ่าย N → P → K อย่างละ 2.5 วินาที → รอน้ำหนักนิ่ง 1 วินาที → ผสม 6 วินาที → รอกดปล่อย → ปล่อย 3 วินาที
- ปุ่ม STOP ค้างสถานะหยุด น้ำหนักไม่เพิ่ม มอเตอร์หยุด ทุกประตูจำลองปิด ต้องกดรีเซ็ตเพื่อเริ่มรอบใหม่
- การรีเซ็ตล้างน้ำหนัก ผลผลิต และประวัติรอบเก่า ใช้ได้ในทุกช่วงของแบบจำลอง
- ระหว่างรอบเปลี่ยนสูตร/น้ำหนักไม่ได้ แต่เปลี่ยนความเร็วจำลองได้
- บันทึกผล JSON รวมสัดส่วน น้ำหนักเป้าหมาย ปริมาณที่จ่ายจริงในแบบจำลอง น้ำหนักคงเหลือ ผลผลิต และประวัติขั้นตอน
- แท็บอุปกรณ์และระบบควบคุมมีข้อมูลหน้าที่ ข้อจำกัด แผนผังไฟ ตัวอย่าง GPIO และเอกสารผู้ผลิต

## สมมติฐานที่ต้องแยกจากของจริง

ภาพผู้ใช้เป็นแนวทาง ไม่ใช่แบบผลิต จอในภาพแรกเป็นแบบสัมผัส แต่เว็บนี้ใช้แนวคิดจอไม่สัมผัสตามคำขอ ขนาดตู้ 40 × 57 × 20 ซม. มาจากภาพที่สาม ซึ่งเป็นขนาดภายนอก รูปร่างและสัดส่วนอุปกรณ์ภายในถูกย่อเพื่อสื่อสารแนวคิด ยังไม่ตรวจสอบการติดตั้ง ระยะเซอร์วิส ความจุ จุดศูนย์ถ่วง หรือแรงรับน้ำหนักจริง

N/P/K ในการจำลองเป็นชื่อช่องวัตถุดิบ ไม่ใช่สารบริสุทธิ์หรือเกรด N–P₂O₅–K₂O อัตราส่วน 1:1:1 ไม่เท่ากับปุ๋ย 15-15-15 ต้องมีข้อมูลธาตุอาหารของแม่ปุ๋ยจริงก่อนคำนวณสูตรเกรด ตัวเลขเป้าหมายบนเว็บปัดเป็นกรัมแบบรักษาผลรวม แต่ตัวจำลองใช้สัดส่วนละเอียด

อัตราการไหล เวลา และน้ำหนักเป็นแบบจำลองเชิงอุดมคติ ไม่มีการวัดจากเซ็นเซอร์ ไม่ได้จำลองการอุดตัน การไหลค้าง การหยุดเกินเป้า ความสม่ำเสมอการผสม หรือแรงกระทำเชิงกล การชั่งจริงต้องออกแบบทางถ่ายแรงผ่าน Load Cell และคาลิเบรตด้วยน้ำหนักอ้างอิง

## แนวทางอุปกรณ์

ใช้ ESP32 DevKit / WROOM-32E หนึ่งตัวเป็นแนวทางเริ่มต้น พร้อม PCA9685 สร้าง PWM ของ 4 Servo จอ I²C ใช้บัสร่วมกันหากที่อยู่ไม่ซ้ำ ตัวอย่างใช้ GPIO 13 ขา ต้องตรวจบอร์ดจริงอีกครั้ง Breadboard เพิ่มจุดเสียบ ไม่ได้เพิ่ม GPIO และไม่เหมาะกับทางจ่ายกระแส Servo/Motor ในตู้จริง

ไฟ 12V จาก Power Supply ไป Motor Driver โดยตรง และแยก DC–DC 6V สำหรับ MG996R กับ 5V สำหรับบอร์ด/จอตามพิกัดและ regulator ของโมดูล ตรวจ logic 3.3V ที่เข้าขา ESP32 และ pull-up I²C ห้ามจ่าย 12V ให้ MG996R หรือจ่ายไฟมอเตอร์จาก GPIO กระแสแหล่งจ่าย ฟิวส์ สาย และ driver ยังเลือกไม่ได้จนรู้กระแส start/stall และโหลดจริง

L298N เป็นตัวเลือกที่ต้องตรวจแรงดันตก ความร้อน และกระแส stall ก่อนยืนยัน อาจใช้ MOSFET driver สำหรับทิศเดียว หรือ H-bridge ถ้าต้องกลับทิศ พร้อมวงจรป้องกันแรงดันย้อนตาม driver

E-Stop จริงต้องมีวงจรความปลอดภัยอิสระจากโปรแกรม และกลไกวาล์วที่เข้าสู่สภาวะปลอดภัยได้ การดับไฟ Servo ไม่ได้ทำให้วาล์วปิดโดยอัตโนมัติ งาน AC, สายดินตู้, ฟิวส์ และการตัดกำลังต้องผ่านการออกแบบ/ตรวจของผู้มีความชำนาญ เว็บไม่ใช่ firmware หรือระบบความปลอดภัยสำหรับเครื่องจริง

## เอกสารอ้างอิง

ตรวจเอกสารผู้ผลิตเมื่อ 10 กันยายน 2026:

- [TowerPro MG996R](https://towerpro.com.tw/product/mg996R/) — แรงดันใช้งาน 4.8–6.6V
- [Espressif GPIO reference](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/peripherals/gpio.html) — GPIO34–39 รับเข้าเท่านั้นและไม่มี internal pull-up/down
- [NXP PCA9685](https://www.nxp.com/docs/en/data-sheet/PCA9685.pdf) — I²C, 16-channel PWM
- [SparkFun HX711](https://learn.sparkfun.com/tutorials/load-cell-amplifier-hx711-breakout-hookup-guide/all) — Load Cell interface / calibration
- [ST L298 datasheet](https://www.st.com/resource/en/datasheet/cd00000240.pdf) — electrical characteristics / saturation voltage
