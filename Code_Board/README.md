# Verdant — ESP32 Fertilizer Mixer/Dispenser

ระบบผสม/ปล่อยปุ๋ยอัตโนมัติ ควบคุมด้วย ESP32 2 บอร์ดคุยกันผ่าน Bluetooth:

- **ESP32 38pin** — "หลังบ้าน" ควบคุม servo ทั้งหมดผ่าน PCA9685 เก็บ state และตัดสินใจทุกอย่าง
- **ESP32 แบบมีหน้าจอ (ESP32-2432S028)** — "หน้าบ้าน" แสดงผล/รับสัมผัสอย่างเดียว ไม่มี logic ของตัวเอง

โค้ดที่ใช้งานจริงตอนนี้อยู่ที่ `Arduino_IDE/esp32_main_dispenser/` (38pin) และ `Arduino_IDE/esp32_touch_hmi_ui/` (จอ) ส่วนไฟล์ PlatformIO (`src/`, `include/`) กับสเก็ตช์ทดสอบอื่น ๆ ใน `Arduino_IDE/` เป็นโค้ดทดสอบ/ดีบักจากขั้นตอนพัฒนาก่อนหน้า

## อุปกรณ์

- ESP32 DevKit 38-pin
- ESP32 แบบมีหน้าจอ ESP32-2432S028 (จอสัมผัส 2.8" ILI9341 + XPT2046)
- PCA9685 16-channel 12-bit PWM driver
- Servo MG996R × 4 (channel 0, 4, 8, 12 — ตัวที่ 4 เป็นประตูปล่อยปุ๋ย)
- มอเตอร์เฟืองทด JGB37-520 DC 12V RPM:100 (ใบพัด/แขนกวนผสม)
- L298N Dual H-Bridge motor driver
- ปุ่มกด 22mm × 4 (เขียว): เลือกสูตร 1/2/3 + ยืนยัน/ปล่อย
- ปุ่ม Emergency Stop แบบ latching (กดล็อก-บิดปลด) × 1 — ต้องมี contact 2 ชุดแยกกัน (NC + NO)
- Load cell + โมดูล HX711 (ตั้งค่า calibration factor = 200000)
- XL4016 DC-DC step-down (ปรับ output ไว้ที่ 5V)
- แหล่งจ่ายไฟหลัก 12V (adapter หรือแบตเตอรี่)

## การต่อสายทั้งหมด

### 1. แหล่งจ่ายไฟหลัก → XL4016

| จาก | ไป |
| --- | --- |
| Adapter 12V (+) | XL4016 `IN+` |
| Adapter 12V (−) | XL4016 `IN−` |

ปรับ trimpot ให้ output = **5V** (วัดตอนไม่มีโหลดก่อนต่อสายถัดไป)

### 2. XL4016 → ESP32 38pin + PCA9685

| จาก | ไป |
| --- | --- |
| XL4016 `OUT+` | ESP32 38pin `5V` |
| XL4016 `OUT−` | ESP32 38pin `GND` |
| XL4016 `OUT+` | PCA9685 `V+` (pin header ข้าง VCC) |
| XL4016 `OUT−` | PCA9685 `GND` (header) |

Terminal block สีเขียว (`POWER` V+/GND) บน PCA9685 ไม่จำเป็นต้องต่อ เพราะเป็นรางไฟเส้นเดียวกับ `V+`/`GND` บน header อยู่แล้ว

### 3. ESP32 38pin ↔ PCA9685 (I2C)

| ESP32 38-pin | PCA9685 (header แถวเดียวกับ VCC) |
| --- | --- |
| GPIO22 | SDA |
| GPIO23 | SCL |
| 3V3 | VCC |
| GND | GND |

`OE` ของ PCA9685 ไม่จำเป็นต้องต่อ (บอร์ดนี้มี pull-down ในตัว ทดสอบแล้ว servo ทำงานปกติแม้ไม่ต่อ)

### 4. PCA9685 → Servo (4 ตัว)

| PCA9685 Channel | Servo |
| --- | --- |
| Ch 0 | Servo 1 (ส่วนผสม A) |
| Ch 4 | Servo 2 (ส่วนผสม B) |
| Ch 8 | Servo 3 (ส่วนผสม C) |
| Ch 12 | Servo 4 (ประตูปล่อยปุ๋ย) |

แต่ละ channel ต่อ `V+`/`GND`/`Signal` ให้ servo ตามลำดับ — **ห้ามจ่ายไฟ servo จากขา 5V/3V3 ของ ESP32** ให้รับไฟจากราง `V+` ของ PCA9685 (มาจาก XL4016) เท่านั้น

### 5. ESP32 จอ ↔ ESP32 38pin — ไฟเลี้ยงเท่านั้น ไม่มีสายสัญญาณ

| ESP32 จอ | ESP32 38pin |
| --- | --- |
| `VIN` | `5V` |
| `GND` | `GND` |

จอกับ 38pin **คุยกันผ่าน Bluetooth** (`VerdantDisplay` ↔ `VerdantMain`) ไม่ใช้สาย UART เลย — `GPIO12`/`GPIO13` บน 38pin มีสาย TX/RX จากจอต่อค้างไว้ทางกายภาพจากช่วงทดลองก่อนหน้า แต่**ไม่ได้ใช้งานในโค้ด**

### 6. แหล่งจ่ายไฟหลัก 12V → L298N → มอเตอร์กวนผสม

L298N รับไฟ **12V เต็ม ๆ ตรงจาก adapter** ไม่ผ่าน XL4016 (เพราะ XL4016 ลดไว้เหลือ 5V แล้ว ไม่พอสำหรับมอเตอร์)

| จาก | ไป | หมายเหตุ |
| --- | --- | --- |
| Adapter 12V (+) | ปุ่ม E-Stop ขา **NC** ขาที่ 1 | ต่อผ่านปุ่มก่อนถึง L298N |
| ปุ่ม E-Stop ขา **NC** ขาที่ 2 | L298N `12V` | ปกติ NC ต่อกัน ไฟผ่านได้ / กดปุ่มล็อก NC เปิด ไฟถูกตัด (สลับขาที่ 1/2 ได้) |
| Adapter 12V (−) | L298N `GND` | ร่วมกับ GND ของทั้งระบบ |
| L298N `OUT1` | มอเตอร์ JGB37-520 สายเส้นที่ 1 | สลับ OUT1/OUT2 ได้ถ้าหมุนผิดทิศ |
| L298N `OUT2` | มอเตอร์ JGB37-520 สายเส้นที่ 2 | |
| L298N `IN1` | ESP32 38pin `GPIO18` | |
| L298N `IN2` | ESP32 38pin `GPIO19` | |
| L298N `ENA` | ปล่อยจัมเปอร์ไว้ (เปิดใช้งานเต็มความเร็วตลอด) | ไม่ต้องต่อ GPIO ถ้ายังไม่ทำ speed control |
| L298N `5V` (ขา output จาก regulator บนบอร์ด) | **ไม่ต้องต่อไปไหน** | ปล่อยว่าง ไม่ต่อรวมกับราง 5V ของ ESP32 กันไฟย้อน |

**Emergency Stop ตัดไฟ 12V ของมอเตอร์ทางฮาร์ดแวร์เสมอ** (ผ่านขา NC ด้านบน) ไม่ขึ้นกับโค้ดหรือ ESP32 — ต่อให้ ESP32 ค้าง กดแล้วมอเตอร์หยุดทันที ปุ่มเป็นแบบ latching ค้างเอง **ไม่ต้องมี relay**

### 6.1 แจ้ง ESP32 ด้วย (contact NO อีกชุดของปุ่มเดียวกัน)

| จาก | ไป |
| --- | --- |
| ปุ่ม E-Stop ขา **NO** ขาที่ 1 | ESP32 38pin `GPIO27` |
| ปุ่ม E-Stop ขา **NO** ขาที่ 2 | `GND` (รวมกับ GND ปุ่มเขียวได้) |

ตอนกดล็อก NO ต่อกัน → GPIO27 อ่านได้ LOW ซอฟต์แวร์จึงหยุด servo ที่กำลังเปิดวาล์วทันที (เช็คทุก 20ms ไม่รอ step ที่ค้างอยู่จบ), ปล่อย servo ทุกตัว, และขึ้นหน้า "EMERGENCY STOP" บนจอ — พอบิดปลดล็อกปุ่ม หน้าจอจะ**กลับหน้าเลือกสูตรเอง** ไม่ต้องกดยืนยัน (ไม่มีอะไรเริ่มทำงานเองจากหน้าเลือกสูตร ต้องเลือกสูตรและกดยืนยันใหม่เสมอ) การผสมที่ถูกขัดจังหวะจะถูกยกเลิก ไม่กลับมาทำต่อ

⚠️ **ก่อนต่อ ตรวจด้วยมัลติมิเตอร์ (continuity)** 2 อย่าง:
1. **ขา NC กับ NO ต้องเป็นคนละ contact block แยกขาดจากกัน** (ไม่มีขากลางร่วม/common) — วัดแล้วต้องไม่ติ๊ดข้ามระหว่างขา NC กับขา NO ถ้ามีขากลางร่วมกัน ไฟ 12V จะไหลเข้า GPIO27 (ทนได้แค่ 3.3V) เสียหายได้
2. ขาไหนเป็น NC/NO จริง: ตอนยังไม่กด NC ต้องติ๊ด NO ต้องไม่ติ๊ด — พอกดล็อกจะกลับกัน

ข้อจำกัด: การหยุด servo เป็นซอฟต์แวร์ (ไม่มีฮาร์ดแวร์ตัดไฟ servo) ถ้า ESP32 แครชกลางคัน มอเตอร์ยังหยุดเพราะฮาร์ดแวร์ แต่ servo อาจค้างตำแหน่งเดิมจนกว่า ESP32 จะรีเซ็ต

### 7. ปุ่มกด 4 ปุ่ม (เขียว) → ESP32 38pin (แทนการแตะจอ)

| ปุ่ม | หน้าสัมผัส | ต่อไป | หมายเหตุ |
| --- | --- | --- | --- |
| ปุ่มเขียว 1 (Recipe 1) | **NO** (ไม่ใช้ NC) | `GPIO32` + `GND` | ขา NO ข้างหนึ่งไป GPIO อีกข้างไป GND |
| ปุ่มเขียว 2 (Recipe 2) | **NO** (ไม่ใช้ NC) | `GPIO33` + `GND` | ขา NO ข้างหนึ่งไป GPIO อีกข้างไป GND |
| ปุ่มเขียว 3 (Recipe 3) | **NO** (ไม่ใช้ NC) | `GPIO25` + `GND` | ขา NO ข้างหนึ่งไป GPIO อีกข้างไป GND |
| ปุ่มเขียว 4 (ยืนยัน/ปล่อย) | **NO** (ไม่ใช้ NC) | `GPIO26` + `GND` | ขา NO ข้างหนึ่งไป GPIO อีกข้างไป GND |

ทำไมต้องเป็น NO ไม่ใช่ NC: โค้ดตั้ง `INPUT_PULLUP` ไว้ (ค่าปกติลอยเป็น HIGH) แล้วตีความ "กด = LOW" — ถ้าใช้ขา NC (ปกติต่อกันอยู่แล้ว) พิน GPIO จะอ่านเป็น LOW **ตลอดเวลาแม้ไม่ได้กด** ทำให้โค้ดเข้าใจผิดว่ากดค้างอยู่ตลอด ต้องใช้ NO เท่านั้น

โค้ดตั้งเป็น `INPUT_PULLUP` ทั้งหมดแล้ว ไม่ต้องต่อตัวต้านทานเพิ่ม แค่ต่อขา NO ด้านหนึ่งเข้า GPIO อีกด้านเข้า GND — กดปุ่ม = ครบวงจร = GPIO อ่านได้ LOW

ก่อนต่อ แนะนำวัดด้วยมัลติมิเตอร์ (continuity) ก่อนว่าขาไหนเป็น NO จริง เพราะตัวเลขที่พิมพ์บน contact block บางรุ่นไม่ตรงกับมาตรฐาน IEC ทั่วไป (ลองกดปุ่มค้างแล้ววัดว่าขาคู่ไหน "ต่อกัน" ตอนกด = NO, คู่ไหน "ต่อกันอยู่แล้วแต่ขาดตอนกด" = NC)

ปุ่มเขียวปุ่มที่ 4 ทำงานตามหน้าจอปัจจุบัน (โค้ดจัดการให้อัตโนมัติ):

| หน้าจอ | กดปุ่มที่ 4 = |
| --- | --- |
| Select Recipe | เปิดหน้า Emergency Release (ปล่อยปุ๋ยฉุกเฉิน) |
| Emergency Release | กดอีกครั้ง = ยืนยันปล่อยปุ๋ย — ถ้าไม่กดภายใน **10 วิ** ยกเลิกเองกลับหน้า Select Recipe |
| Recipe Detail | เริ่มผสม |
| Mix Done | ปล่อยปุ๋ย |
| Power Recovery | ปล่อยปุ๋ยทันที (Release Now) |
| หน้า EMERGENCY STOP | ไม่ใช้ปุ่มนี้ — บิดปลดปุ่ม E-Stop แล้วกลับหน้าเลือกสูตรเอง |

แก้เวลายกเลิกได้ที่ `EMERGENCY_CONFIRM_TIMEOUT_MS` ในโค้ด 38pin

### 8. Load Cell → HX711 → ESP32 38pin

**HX711 ↔ ESP32 38pin**

| HX711 | ESP32 38pin | หมายเหตุ |
| --- | --- | --- |
| `VCC` | `3V3` | ใช้ 3.3V เพื่อให้สัญญาณ DT เป็น 3.3V ปลอดภัยกับ GPIO (อย่าใช้ 5V) |
| `GND` | `GND` | ร่วมกับ GND ทั้งระบบ |
| `DT` (DOUT) | `GPIO16` | |
| `SCK` | `GPIO17` | |

**Load cell ↔ HX711** (สีสายต่างกันตามรุ่น ดูตามที่พิมพ์ข้างสาย/ข้างตัว load cell)

| Load cell (สีที่พบบ่อย) | HX711 |
| --- | --- |
| แดง (Excitation +) | `E+` |
| ดำ (Excitation −) | `E−` |
| ขาว (Signal −) | `A−` |
| เขียว (Signal +) | `A+` |

ถ้าน้ำหนักที่อ่านได้ติดลบตอนวางของ ให้สลับสาย `A+` กับ `A−`

**ค่าที่ตั้งในโค้ด** (`esp32_main_dispenser.ino`): `LOADCELL_CALIBRATION_FACTOR = 200000` ค่านี้ใหญ่มาก ผมเดาว่าหน่วยที่ได้จาก `get_units()` เป็น **กิโลกรัม** จึงคูณ 1000 เป็นกรัมด้วย `LOADCELL_UNITS_TO_GRAMS` — ถ้าค่าที่ Serial Monitor ขึ้นเพี้ยนไป 1000 เท่า ให้เปลี่ยนตัวเลขนี้เป็น `1.0`

**การปล่อยปุ๋ยตามน้ำหนัก** (ลำดับ N → P → K = servo ช่อง 0 → 4 → 8):

1. ก่อนเริ่มสูตร tare ตาชั่งเป็น 0 (**ภาชนะต้องว่าง**) ปุ๋ยรวมต้องไม่เกิน 1.00 kg และถ้าน้ำหนักเกิน 1.25 kg จะปิดวาล์วแล้วขึ้นหน้า FAULT
2. เปิด servo ตัวแรก แล้วอ่าน load cell ต่อเนื่อง ปิดวาล์วเมื่อ `น้ำหนักที่เพิ่ม >= เป้าหมาย − ค่า Calibrate`
3. รอให้ load cell **นิ่ง** (อ่านต่อเนื่อง 5 ค่าห่างกันไม่เกิน 2 g) ค่าที่นิ่งคือปริมาณจริง แล้วจึงเปิด servo ตัวถัดไป โดยเริ่มนับจากน้ำหนักที่นิ่งนั้น
4. ครบทุกตัวแล้วจึงสั่งมอเตอร์กวน ความคลาดเคลื่อนที่เหลือไม่แก้ ปล่อยไปตามจริง

**ค่าที่ต้องปรับ อยู่บนสุดของโค้ด 38pin** (`esp32_main_dispenser.ino`):

| ค่า | ความหมาย |
| --- | --- |
| `RECIPE_TARGET_G[สูตร][N,P,K]` | เป้าหมายกรัมของแต่ละสูตร (สูตร 1 = 460/0/0, สูตร 2 = 150/150/150, สูตร 3 = 120/240/120) ไม่ต้องแก้ตอนปรับเครื่อง |
| `CALIBRATION_OFFSET_G[สูตร][N,P,K]` | ปิดวาล์วก่อนถึงเป้ากี่กรัม เพื่อชดเชยปุ๋ยที่ยังตกค้างอยู่ในอากาศ เช่น เป้า 460 ใส่ 160 → ปิดวาล์วที่ 300 g แล้วค่านิ่งจริงอาจได้ประมาณ 440 g |

ตอนปรับ ดู Serial Monitor ทุกครั้งที่ปล่อยเสร็จจะพิมพ์ `Ingredient N: closed at 300.4 g, settled at 441.2 g (target 460, error -18.8 g)` ถ้าค่านิ่งเกินเป้าให้เพิ่ม offset ถ้าขาดให้ลด **ค่า offset ตั้งเป็น 0 ทั้งหมดในโค้ดปัจจุบัน** (วาล์วปิดเมื่อถึงเป้าพอดี) ยังไม่ได้วัดจริง

**บนหน้าจอ**: ทุกหน้ามีค่า `Load cell: x.xxx kg` ที่แถบล่าง หน้า Recipe แสดงเป้าหมาย N/P/K ส่วนหน้า Mixing เป็นกราฟแท่งซ้อน (N เขียว, P ส้ม, K ฟ้า) สูงขึ้นตามปุ๋ยที่ตก เส้นแดง = 1.00 kg ขีดขาวข้างแท่ง = จุดที่แต่ละตัวควรไปถึง และหน้า Mixing complete แสดงน้ำหนักจริงของ N/P/K กับผลรวม

**หน้า FAULT** (กดปุ่ม 4 หรือแตะ OK เพื่อกลับ): HX711 ไม่ตอบ, วาล์วเปิดเกิน 60 วินาทีแล้วน้ำหนักไม่ถึง (ปุ๋ยหมด/วาล์วตัน), น้ำหนักเกิน 1.25 kg ซึ่งทั้งหมดจะปิดวาล์วทันที

ตอนเปิดเครื่องจะ tare เป็น 0 เช่นกัน (**ต้องไม่มีของวางบนภาชนะตอนเปิดเครื่อง**)

## ⚠️ กฎสำคัญก่อนอัปโหลดโค้ดใหม่เข้า 38pin

**ต้องถอดสายอื่นทั้งหมดออกจาก ESP32 38pin ก่อนเสียบ USB อัปโหลด** เหลือไว้แค่สาย USB เส้นเดียว (ถอด I2C ไป PCA9685, ถอดไฟ/GND จาก XL4016 ออกให้หมด) แล้วค่อยต่อกลับหลังอัปโหลดเสร็จ

สาเหตุ: เคยเจอปัญหา `Serial data stream stopped` / `MD5 mismatch` ตอนอัปโหลดซ้ำ ๆ ไล่สาเหตุจนพบว่าเป็นเพราะกราวด์ร่วมกับวงจร PCA9685/XL4016 ทำให้สัญญาณรบกวนเข้าไปกวน USB ระหว่างขั้นตอน erase/write ที่ใช้เวลานาน พอแยกสายออกให้เหลือ USB อย่างเดียวก็อัปโหลดผ่านปกติทันที

2. ถอดสายอื่นออกจาก 38pin เหลือ USB เส้นเดียว (ตามกฎด้านบน) แล้วอัปโหลด `Arduino_IDE/esp32_main_dispenser/esp32_main_dispenser.ino`
3. ต่อสายทั้งหมดกลับเข้าที่เดิม
4. อัปโหลด `Arduino_IDE/esp32_touch_hmi_ui/esp32_touch_hmi_ui.ino` เข้าบอร์ดจอ
5. เปิด Serial Monitor ทั้งสองบอร์ด — 38pin ควรขึ้น `Starting Bluetooth SPP server...`, จอควรขึ้น `Attempting Bluetooth connect to main board...` แล้วตามด้วย `-> SCREEN RECIPE_SELECT 1`
6. หน้าจอควรเข้าสู่หน้า "Select Recipe" ได้เอง

### ปรับสูตรผสม/มุม servo

แก้ค่าใน `Arduino_IDE/esp32_main_dispenser/esp32_main_dispenser.ino`:

- `RECIPE_TARGET_G` / `CALIBRATION_OFFSET_G` — เป้าหมายกรัมและค่า Calibrate ต่อสูตร (อยู่บนสุดของไฟล์ ดูหัวข้อ 8)
- `WEIGHT_LIMIT_G` / `WEIGHT_HARD_LIMIT_G` / `STABLE_TOLERANCE_G` / `STABLE_TIMEOUT_MS` / `DISPENSE_TIMEOUT_MS` — ขีดจำกัดน้ำหนัก, เกณฑ์ว่าค่านิ่ง, เวลารอสูงสุด
- `GATE_OPEN_ANGLE` / `GATE_CLOSED_ANGLE` — มุมเปิด/ปิดของ servo แต่ละตัว
- `STIR_DURATION_MS` — เวลากวนผสมของมอเตอร์ต่อสูตร (placeholder เช่นกัน ยังไม่ได้วัดจริง)
- `I2C_SDA_PIN` / `I2C_SCL_PIN` — พิน I2C ถ้าต่อสายต่างจากตารางด้านบน
- `MOTOR_IN1_PIN` / `MOTOR_IN2_PIN` — พินคุมทิศทางมอเตอร์ผ่าน L298N
- `BTN_RECIPE_1_PIN` / `BTN_RECIPE_2_PIN` / `BTN_RECIPE_3_PIN` / `BTN_CONFIRM_PIN` — พินปุ่มกดเขียว 4 ปุ่ม
- `HX711_DT_PIN` / `HX711_SCK_PIN` / `LOADCELL_CALIBRATION_FACTOR` / `LOADCELL_UNITS_TO_GRAMS` — พินและค่า calibration ของ load cell

## โค้ดทดสอบ/ดีบัก (ไม่ใช่โค้ดใช้งานจริง)

ใน `Arduino_IDE/` ยังมีสเก็ตช์ทดสอบจากขั้นตอนพัฒนาไว้อ้างอิง:

- `pca_bare_test/` — ทดสอบ PCA9685 + servo ตัวเดียว แบบ bare minimum ไม่ต้องพิมพ์คำสั่ง
- `servo_sweep/`, `servo_sweep_auto/`, `servo_sweep_multi/` — ทดสอบ sweep servo แบบต่าง ๆ
- `Scan_PCA9685/` — I2C scanner

ไฟล์ PlatformIO เดิม (`src/`, `include/board_config.h`, `platformio.ini`) เป็นโครงเก่าจากช่วงเริ่มโปรเจกต์ ยังคอมไพล์ได้แต่ไม่ได้ใช้งานคู่กับระบบ Bluetooth/dispenser ปัจจุบัน
